# 13:00 — subs-ui

## Changed
- `/subscriptions`: server-rendered list. Stat cards (Active, MRR normalised to monthly, invoices due in 7 days) link to filtered lists (`?status=active`, `?due=7`). Status chips, search by number or customer, 20 per page, sortable Number / Start date / Next invoice / Recurring via `?sort=&dir=` (aria-sort). Cards below md. Aggregates run in SQL; about 200 ms on 3,000 subs in dev.
- `/subscriptions/new`: create form (searchable customer combobox, plan with list price, template prefill, dates, payment terms, `LineEditor` with live totals, client validation mirroring `createSubscriptionSchema`, server errors as toasts and inline). Enter in the last quantity adds a line, Ctrl+Enter saves.
- `/subscriptions/[id]`: status bar with only the valid actions (Draft: Send quotation; Quotation: Confirm; Confirmed: Activate; Active: Create invoice, Pause, Renew, Close; Paused: Resume, Close). Close needs a reason (dialog), Renew shows the new expiry. Totals use `priceInvoice` with the discount rules valid on the next invoice date, so they match that invoice. Side panel lists generated invoices (Overdue shown as a derived badge).
- New read route `GET /api/customers?q=&limit=` (ADMIN/STAFF) with tests. Pure logic in `src/app/(app)/subscriptions/logic.ts` with Vitest tests.
