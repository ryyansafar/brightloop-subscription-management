## Changed
- Catalog APIs are on main (122 tests green). All return `{ ok, data | error }`. Read: ADMIN + STAFF. Write: ADMIN only. Customers get 403.
  - `/api/products` (+ `/{id}`, `/{id}/variants`, `/{id}/variants/{variantId}`): fields name, type (SOFTWARE|ADDON|SERVICE), salesPrice, costPrice (paise), notes, active, variants[{attribute,value,extraPrice}]. Filters: `?q=`, `?type=`, `?active=1|0`, `?page=`.
  - `/api/plans` (+ `/{id}`): name, price, periodUnit DAY|WEEK|MONTH|YEAR, periodCount, minQuantity, availableFrom/To, autoClose, closable, pausable, renewable, active.
  - `/api/taxes` (+ `/{id}`): name, rateBps (1800 = 18%), active.
  - `/api/discounts` (+ `/{id}`): name, kind FIXED|PERCENT, value (paise or basis points), minAmount, minQuantity, startsAt, endsAt, usageLimit (null = unlimited), scope PRODUCT|SUBSCRIPTION, productId (PRODUCT only), active. List filter `?state=running|expired|upcoming|exhausted`. `usedCount` is read-only.
  - `/api/templates` (+ `/{id}`): name, planId, validityDays, lines[{productId, variantOptionId?, quantity}]. PATCH with `lines` replaces all lines atomically.
- PATCH takes any subset of fields. DELETE retires products, plans, taxes and discounts (`active: false`); templates are really deleted; a variant in use cannot be deleted (409).
- Rules enforced server-side: no negative prices, percent <= 100%, end after start, usage limit >= 1 and not below uses already counted, PRODUCT discounts need a product, plan period cannot change while subscriptions bill on it.
- Also done for Fathima: indexes on SubscriptionLine.subscriptionId / InvoiceLine.invoiceId (run `npx prisma migrate dev`), seeded payments capped at today, `npm run seed:full` now works on Windows.
