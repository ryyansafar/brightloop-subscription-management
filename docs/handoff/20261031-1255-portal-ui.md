# 12:55 — portal-ui

## Changed
- Customer portal at `/portal`, `/portal/invoices`, `/portal/invoices/[id]`, `/portal/subscriptions/[id]` (src/app/(app)/portal/**). All data functions (`queries.ts`) filter by the session's customer id and hide DRAFT records; URL ids are untrusted, so another customer's invoice renders the not-found page. Renew shows the new expiry; Close requires a reason; both are disabled with a visible reason when not allowed. No Pause and no Pay (the API refuses them). Invoices: 10 per page, status chips, number search, View and Print.
- Admin staff page at `/admin/staff`: admin-only on the page and in `listStaffUsers`; add-staff dialog with the shared password checklist. The API only creates STAFF, so Role is shown as fixed, with no Edit/Disable or Last sign-in (schema and API have neither).
