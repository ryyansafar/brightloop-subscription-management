- `src/app/(app)/layout.tsx` now uses the real session: it calls Pankaj's `getSessionUser()` (no auth logic copied) and filters the sidebar by role. - Dashboard on `seed:full` data: all KPIs in about 70 ms, page about 0.5 s, numbers still match a manual count.
