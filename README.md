# Brightloop Subscription Management System

Odoo x Make-A-Ton 9.0 Kochi Hackathon 2026 — Virtual Round.

One platform to run plans, subscriptions and recurring billing: products and variants, plans, quotation templates, subscriptions, invoices, payments, discounts, taxes, role-based access and a finance dashboard.

## Status

Work in progress.

## Roles

- **Admin** — full control: products, plans, taxes, discounts, staff accounts
- **Internal staff** — day-to-day subscriptions, invoices, payments (limited access)
- **Customer** — portal with their own subscriptions and invoices only
